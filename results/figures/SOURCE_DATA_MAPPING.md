# Source-data mapping (reader-facing)

Every figure is generated by a script that reads evidence-locked result
files; no manual data entry. Per-figure numerical source data ship in
`results/figures/source_data/`; experiment-level result files under
`results/<experiment>/` as listed below.

## Main-text figures

| Figure | Source data | Result files |
|---|---|---|
| Fig. 1 framework | `source_data/fig1_source_data.csv` | protocol metadata |
| Fig. 2 transfer matrix | `source_data/fig2_source_data_transfer_matrix.csv` | `results/transfer_coordinate/` (transfer/reverse matrices, CIs, seed scan) |
| Fig. 3 transfer boundary | `source_data/fig3_source_data_*.csv` | `results/gbr_transfer/`, `results/domain_shift/` |
| Fig. 4 anchor | `source_data/fig5_source_data*.csv` | `results/step2_persistence_v2/` |
| Fig. 5 gated residual | `source_data/fig6_source_data_*.csv` | `results/structural_ablation/` |
| Fig. 6 XGBoost control (a-e) | `source_data/SX_source_data.csv` | `results/xgb_transfer_control/`, `results/invariant_predictor_screen/` |
| Fig. 7 diagnostics | `source_data/fig4_source_data_*.csv` | `results/domain_shift/`, `results/thermal_attribution/` |
| Fig. 8 unified pipeline | experiment AUDIT | `results/response_surface_susceptibility_mechanism/` |
