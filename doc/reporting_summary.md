## Statistical parameters

- All statistical parameters (confidence intervals, resampling scheme,
  seed) are reported in the Methods and the relevant figure legends.
- Primary inference basis: paired week-block bootstrap, 1,000 shared
  resamples, seed 42; spatial grid-cell cluster bootstrap (405 CARIB
  cells) as robustness check.
- Pre-specified operating threshold tau = 0.90, never selected on any
  target domain.
- Symmetry of CIs: all reported CIs are two-sided bootstrap percentile
  intervals [to be completed: confirm two-sided for every interval].

## Sample size

  (419 severe); GBR n = 19,065 (676 severe); CARIB n = 83,025
  (1,356 severe).
- No sample-size calculation was performed: the study is a retrospective
