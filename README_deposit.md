# Zenodo Deposit Guide (one-click final step)

1. Go to https://zenodo.org and log in.
2. New upload -> choose file: zenodo_release.zip (next to this directory).
3. Copy the fields from zenodo_deposit_metadata.json:
   - Title: Thermal-stress anchoring reveals transferable and basin-specific coral thermal risk
   - Creators: Bin Zeng; Rui Wang; Houpu Li (affiliations and ORCIDs filled)
   - Description: as in the JSON
   - License: MIT | Access: Open | Upload type: Publication / Article
4. Related identifiers: keep the two dataset DOIs already in the JSON
   (GCBD 10.1038/s41597-022-01121-y, CRW 10.3390/rs12233856); add the
   manuscript DOI once the paper is accepted.
5. Publish, copy the DOI, and send it back: the Code availability
   placeholder "[placeholder: repository DOI to be assigned]" in
   main_manuscript.md will then be replaced and the docx re-rendered.
